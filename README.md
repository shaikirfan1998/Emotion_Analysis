# Emotion_Analysis
Emotion analysis using LLM'S
This project explores the use of Large Language Models (LLMs) for multi-class emotion classification on YouTube comments, focusing on six emotions: joy, sadness, anger, fear, love, and surprise. The study compares Mistral-7B and LLaMA 3.1 8B across zero-shot, few-shot, and fine-tuned learning settings using Kaggle datasets and real-world YouTube comments. Efficient fine-tuning techniques like QLoRA and LoRA were applied on consumer-grade hardware to adapt the models for the task.
